📋 How to Test

  1. Start the backend: cd backend && uv run main.py
  2. Start the frontend: cd frontend && npm run dev
  3. Navigate to /setup
  4. Configure preferences and save
  5. Navigate away and back to /setup
  6. Verify your settings are restored
  7. Test API key persistence separately

✅ Expected Behavior

  • New users: See default values and "Welcome to Quorum AI" title
  • Returning users: See their saved values and "Update Your Preferences" title
  • All settings persist: Voting strategy, confidence threshold, max proposals, blacklisted/whitelisted proposers
  • API keys persist: Stored securely via StateManager encryption

🏗️ Architecture

Frontend: Setup page loads preferences → PreferenceForm displays them → User saves → API call updates backend

Backend: API endpoints → UserPreferencesService → StateManager (encrypted) + File fallback

Result: Settings persist between application restarts and user sessions
